Build and run locally with the Qt 5 tools already installed on this computer:

cd /home/konrad/Desktop/sj-sim
mkdir -p build-linux && cd build-linux
qmake ../sj-sim.pro CONFIG+=release && make -j"$(nproc)"
cp -a ../flags ../userData ../translations .
lrelease translations/translation_en.ts -qm translations/translation_en.qm
./sj-sim

This is a quick local build for this computer. GitHub Actions separately builds
the portable release against the older Linux compatibility baseline.
